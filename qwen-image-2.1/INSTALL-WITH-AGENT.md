# Задание агенту: установить Qwen-Image-2.1 на одной GPU

Этот файл можно передать агенту целиком. Он должен работать с папкой
`qwen-image-2.1` из https://github.com/alesha-pro/tools или с приложенной копией
этой папки. Соседние README, scripts, install и workflows являются частью комплекта.

## Задача и результат

Установи локальную Qwen-Image-2.1 в ComfyUI на **одной GPU**. Настрой генерацию по
тексту, редактирование, прозрачный PNG и приложенные workflows. Доведи задачу до
реальной картинки, а не только до установленного окружения.

Изучи `README.ru.md`, `install/versions.json`, `install/models.json` и фактическую
машину. Если у пользователя уже есть рабочий ComfyUI, сначала используй маршрут
добавления моделей и workflows. Не обновляй его Python-зависимости вслепую.
Второй вариант — новая отдельная установка.

По завершении сообщи рабочий URL, команды запуска, пути к workflows и результатам,
выбранную GPU, версии, фактическое время теста и ограничения проверки. Открой
полученный PNG, проверь, что он соответствует промпту. Оставь сервер работающим,
если пользователь не попросил остановить.

## Что уже разрешено

В рамках просьбы установить модель можно создать отдельный checkout/venv,
скачать три официальных файла весов общим размером 17.28 GB, скопировать workflows
и выполнить несколько проверочных генераций. Не спрашивай повторное разрешение
на эти обычные действия, если пользователь не задал другие ограничения.

Не публикуй ничего наружу. Не используй платные API. Не меняй power limit,
драйвер, системный Python или чужие контейнеры автоматически. Не останавливай
чужие GPU-процессы. Не делай `pkill python`, `killall` или перезагрузку машины.
Если все карты заняты чужими задачами, подготовь установку без генерации и
объясни конкретное препятствие. Истечение времени не является разрешением занять
занятую карту.

## 1. Проверка машины

Определи ОС, архитектуру CPU, Python, Git, свободный диск, RAM, GPU и драйвер.
Для NVIDIA выполни `nvidia-smi`, посмотри не только процент загрузки, но и процессы
и занятую память. Выбери одну карту. Проверь, не занят ли порт 8188.

Проверенный профиль: NVIDIA RTX 3090 24 GB, Linux. Рекомендуется 64 GB RAM и
45 GB свободного диска. На 16 GB VRAM возможен offload, но это не проверенный
здесь профиль; начинай с 1 MP и не обещай 2K до теста. На AMD/Intel/Mac этот CUDA
installer не запускай: используй официальную инструкцию для платформы и отдельно
проверь поддержку модели. Если подходящего пути нет, укажи это честно.

В репозитории могут быть чужие незакоммиченные изменения. Не сбрасывай и не
перезаписывай их. Если `qwen-image-2.1` ещё отсутствует в публичном checkout,
используй переданную пользователем папку; не подменяй её похожим сторонним пакетом.

## 2. Установка

Команды ниже выполняются из папки `tools/qwen-image-2.1`.

### Linux / WSL2

На Ubuntu/Debian при отсутствии инструментов нужны `git`, `python3`,
`python3-venv`. Системные пакеты устанавливай штатным способом с учётом прав
пользователя. Нужен Python 3.10–3.13, рекомендуется 3.12.

```bash
python3 install/setup.py check
python3 install/setup.py install --dir "$HOME/ComfyUI-Qwen21"
"$HOME/ComfyUI-Qwen21/.venv/bin/python" install/download_models.py --models-dir "$HOME/ComfyUI-Qwen21/models"
python3 install/setup.py launch --comfy "$HOME/ComfyUI-Qwen21" --gpu 0 --port 8188
```

Не меняй `$HOME` или `$CODEX_HOME`. Можно выбрать другой новый каталог установки.
Установщик использует `uv`, если он есть, иначе venv/pip. Сервер запускается в
foreground; для фонового запуска используй штатный менеджер процессов своей
среды, сохрани лог и точный PID/имя созданной службы.

### Windows PowerShell

```powershell
py -3.12 install/setup.py check
py -3.12 install/setup.py install --dir "$HOME/ComfyUI-Qwen21"
& "$HOME/ComfyUI-Qwen21/.venv/Scripts/python.exe" install/download_models.py --models-dir "$HOME/ComfyUI-Qwen21/models"
py -3.12 install/setup.py launch --comfy "$HOME/ComfyUI-Qwen21" --gpu 0 --port 8188
```

Windows-команды предусмотрены, но не являются заявлением о проведённом Windows
тесте. Не включай установку unsigned drivers или изменение системной политики
PowerShell: запуск Python по полному пути не требует activation script.

### Уже существующий ComfyUI

Найди его настоящий Python и `main.py`. Проверь `TextEncodeQwenImage21` через
`GET /object_info` или код. При необходимости обновляй только штатным механизмом
этой установки и учитывай активные задания. Копирование workflows:

```bash
python3 install/setup.py workflows --comfy /actual/path/to/ComfyUI
```

Замени пример пути фактическим. Установщик dependencies здесь не нужен.
Скачай модели в `models/` или подключи их через `extra_model_paths.yaml`, если
они уже лежат в центральном хранилище. Проверь SHA-256 из `install/models.json`.
Не создавай ещё одну копию 17 GB без необходимости.

## 3. Правильные веса и запуск на одной GPU

Все три файла взяты из `Comfy-Org/Qwen-Image-2.1`:

- `models/diffusion_models/qwen_image_2.1_int8_convrot.safetensors`
- `models/text_encoders/qwen3vl_8b_int8_convrot.safetensors`
- `models/vae/qwen_image_2.1_vae_bf16.safetensors`

`CLIPLoader`: type `qwen_image`, device `default`.
`UNETLoader`: weight_dtype `default`.

`setup.py launch --gpu N` задаёт `CUDA_VISIBLE_DEVICES=N`, поэтому процесс
использует одну физическую карту. Не запускай несколько GPU workers для этого
гайда. Выбранную карту внутри процесса ComfyUI называет `cuda:0`.

По умолчанию слушай `127.0.0.1`. Для удалённой машины используй SSH-туннель.
Не выставляй ComfyUI в публичный интернет. Пример туннеля с локального компьютера:

```bash
ssh -N -L 8188:127.0.0.1:8188 user@server
```

Подставь переданный пользователем SSH-адрес. Если локальный 8188 занят, используй
`-L 8189:127.0.0.1:8188` и открой `http://127.0.0.1:8189`.

## 4. Приёмка

Сначала проверь `GET /system_stats`, `GET /object_info` и `GET /queue`.
Ноды и имена моделей должны присутствовать, очередь не должна содержать чужие
активные задания перед тестом. Не прерывай их.

Используй Python созданного окружения. Пример Linux:

```bash
"$HOME/ComfyUI-Qwen21/.venv/bin/python" scripts/generate.py --mode t2i --seed 42 --out outputs
"$HOME/ComfyUI-Qwen21/.venv/bin/python" scripts/generate.py --mode rgba --seed 43 --out outputs
```

Передай `--url http://127.0.0.1:PORT`, если выбрал другой порт.
После T2I найди фактически сохранённый PNG и передай его в edit:

```bash
"$HOME/ComfyUI-Qwen21/.venv/bin/python" scripts/generate.py --mode edit --image /actual/path/to/generated.png --seed 44 --out outputs
```

Путь здесь пример, обязательно замени его. После успеха 1 MP попробуй `--mode 2k`
с новым seed. Для двух референсов есть `--mode references --image ... --reference ...`.

Для каждого теста:

1. Дождись `status_str=success` в `/history/{prompt_id}`.
2. Проверь реальный файл, разрешение и успешное PNG-декодирование.
3. Открой изображение и оцени соответствие запросу.
4. Для RGBA проверь настоящую alpha, а не нарисованную клетчатую подложку.
5. Сохрани seed, API-граф, версии, тайминги и ограничения.

Скрипт сохраняет граф, submission, history и result в отдельную папку запуска.
При таймауте серверная задача может продолжать работать: проверь её prompt_id,
прежде чем отправлять дубликат. Одинаковый граф может быть взят из кэша, поэтому
для измерения генерации используй новый seed.

Не называй установку полностью проверенной, если есть только HTTP 200 или
валидный JSON. Если 2K не помещается, оставь рабочий 1 MP workflow и явно сообщи
предел; не выдавай апскейл за нативную 2K-генерацию.

## 5. Workflows и объяснение пользователю

Передай пять UI JSON из `workflows/`, не перепутай их с `workflows/api/`.
Объясни, где меняются prompt, ширина/высота, seed и шаги. В KSampler есть
`control_after_generate=randomize`; для повторения выбери `fixed`.

Стартовые настройки: Euler/simple, CFG 1, denoise 1, batch 1, 40 шагов на 1 MP.
Широкий 2K workflow: 2048 × 1152 и 50 шагов. Это 2.36 MP, в отличие от
2048 × 2048 с 4.19 MP. Не называй их одинаковой нагрузкой.

Для edit: загрузить картинку, указать изменение и что сохранить. Выходной latent
берётся из TextEncodeQwenImage21, resolution задаёт площадь с сохранением
пропорций первого референса. Для двух картинок адресация `<image1>`, `<image2>`.

Prompt enhancer необязателен и в эту установку не входит. PE-I2I нельзя выдавать
за PE-T2I. Не добавляй ещё одну LLM на ту же GPU до успешного базового теста.

## 6. Типичные препятствия

- `TextEncodeQwenImage21` отсутствует: старая версия ComfyUI или ошибка импорта;
  изучи лог, а не устанавливай случайные custom nodes.
- OOM: batch 1, 1024 square, меньше референсов, CLIPLoader device `cpu`, при
  необходимости `--lowvram`. Каждое изменение проверь отдельным прогоном.
- Модель не видна: папка, имя файла, extra_model_paths и перезапуск после
  изменения конфигурации. Проверяй контрольную сумму.
- Нет CUDA: проверь выбранный Python, PyTorch CUDA build и драйвер.
- torchaudio: он нужен при старте ComfyUI. Используй согласованный набор
  Torch 2.11.0, torchvision 0.26.0 и torchaudio 2.11.0; не смешивай версии.
- Библиотека отсутствует после pip install: пакет мог попасть в другой Python.
