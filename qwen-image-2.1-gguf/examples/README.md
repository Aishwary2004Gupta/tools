# Validation images

These are original, unretouched PNGs generated by the Q4_K_M installation.
The procedural color swatch is an input, not a model output.

| File | Role |
|---|---|
| `qwen21-example.png` | Text-to-image output and base image for editing |
| `qwen21-reference.png` | Blue swatch for the second reference input |
| `edited-blue.png` | Red teapot changed to cobalt blue |
| `two-reference-edit.png` | Teapot color changed using the blue swatch |
| `low-memory-512.png` | 512 square output from the tightest offload test |
| `transparent-teapot.png` | Teapot generated with an alpha channel |

The RGBA file can contain purple RGB values in nearly transparent pixels.
Use an alpha-aware viewer or composite it over a background. The model's alpha
is a generated matte, so inspect edge quality before using it in a final design.

PNG metadata includes the submitted API graph and UI workflow. Generation
settings and measured memory are in [the validation report](../docs/validation.md).
